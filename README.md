# 🐾 Animal Shelter Outcome Predictor

Predicting shelter animal outcomes with **Machine Learning**.  
The model analyzes features like **species, breed, age, color, health, and intake type** to classify whether an animal will be **Adopted**, **Transferred**, or **Returned to Owner**.

---

## 📊 Dataset
- **29,421 rows × 37 columns**  
- Target: `outcome_type` (9 classes)  
- Main outcomes: Adoption, Transfer, Return to Owner  

---

## ⚙️ Tech Stack
- Python, Pandas, NumPy  
- scikit-learn (RandomForest)  
- Matplotlib  
- Google Colab  

---

## 📈 Results
- **Accuracy:** 94%  
- Strong predictions for Adoption & Transfer  
- Rare classes remain challenging
